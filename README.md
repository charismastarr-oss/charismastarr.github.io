# charismastarr.com

Static site for Charisma Starr Coaching & Consulting, hosted on GitHub Pages.

## Pages
- `index.html`: Home
- `services.html`: Coaching and Speaking
- `about.html`: About
- `contact.html`: Contact form, hours, phone, email

## Other files
- `css/style.css`: all styles. Brand colors and fonts are at the top.
- `js/site.js`: mobile menu and contact form service preselect
- `images/`: logo art, headshot, hero art
- `CNAME`: tells GitHub Pages the custom domain (charismastarr.com)

## Editing later
On GitHub, open a file, click the pencil icon, change the text, and commit. The site updates in about a minute.

## Things that live outside this repo
- Contact form: Formspree (form ID is in `contact.html`)
- Booking: the Calendly link appears on `index.html`, `services.html`, and `contact.html`
